# /fix — 问题修复

## 流程

### 阶段 1: 问题收集 + 调试准备

- 收集复现步骤、期望行为、实际行为
- 分析代码，在可疑位置添加 console.log 调试日志
- **⏸ 请用户运行复现，提供控制台日志输出**

### 阶段 2: 定位分析

- 根据日志 + 代码分析，定位根因，提出修复方案
- **⏸ 向用户汇报分析结论（根因 + 修复方案），明确询问"这个分析是否符合你看到的现象？"，等待用户确认或纠正**

### 阶段 3: 修复实现

- 按确认后的方案修复
- **⏸ 请用户运行验证，确认问题是否解决**
- 如未解决：根据用户反馈继续调整，回到阶段 2 重新分析

### 阶段 4: 收尾（用户确认问题解决后）

- 清理调试代码（console.log、debugger）
- 执行 lint + typecheck
- 调用 code-reviewer 检查
- 展示变更摘要
