# 计划归档工作流

处理已完成的需求计划。

## 触发条件

用户输入需求编号或路径时触发

## 流程

### 1. 读取状态

读取 `docs/plans/<需求编号>/README.md`，检查计划分解表格，确认所有计划是否完成。

### 2. 输出选项

向用户展示归档选项：

```
[1] 删除（永久删除）
[2] 移动到归档目录（~/dev/archived-issues/）
[3] 保留（不处理）
```

### 3. 执行选择

根据用户选择执行：
- **删除**：`rm -rf docs/plans/<需求编号>/`
- **移动**：`mv docs/plans/<需求编号>/ ~/dev/archived-issues/`
- **保留**：不执行任何操作

### 4. 输出结果

告知用户执行结果，如：
- 已删除 `docs/plans/UAC-123/`
- 已移动到 `~/dev/archived-issues/UAC-123/`
- 已保留 `docs/plans/UAC-123/`
