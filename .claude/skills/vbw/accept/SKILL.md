# VBW 人工验收

用户逐项确认验收清单，通过后标记任务完成并更新 README。

## 前置条件

review 阶段已通过，代码质量和规范对齐验证完成。

## 流程

### 1. 展示验收清单

读取当前任务的**验收清单**，逐项引导用户核验：

1. 展示验收清单（每项为 `- [ ]` 格式）
2. 用户逐项确认或反馈问题
3. 通过的项目标记为 `- [x]`
4. 未通过的项目记录问题，进入修复循环

同时向用户展示：
- 列出本次任务做了什么（关键变更摘要）
- 展示关键代码片段（如有必要）

### 2. 验收循环

- 用户发现问题 → 修复 → 重新展示相关验收项
- 所有验收项通过 → 继续步骤 3

**重要**：验收以清单为准，不能跳过或笼统确认（如"看起来没问题"）。

### 3. 更新 README 状态

在 README.md 中标记任务完成：`- [ ] [slug](slug.md)` → `- [x] [slug](slug.md)`

### 4. 循环或收尾

- **还有未完成任务**：回到 implement 阶段，继续下一个任务
- **所有任务完成**：进入步骤 5

### 5. 需求级一致性检查

写总结前进行最终检查：

- [ ] 每个 task 的已确定内容与实际代码一致
- [ ] README 描述的核心功能全部被任务覆盖（对照 README）

**所有项必须通过，否则修复后再继续。**

### 6. 填写总结

在 README.md 的总结区域填写成果提炼：

- 实现了什么功能
- 关键技术决策
- 值得注意的问题或发现

**注意：总结是成果提炼，不是 git log 副本。**

## 门禁条件

- [ ] 用户逐项确认验收清单，全部 `[x]`
- [ ] 需求级一致性检查通过
- [ ] 总结已填写
