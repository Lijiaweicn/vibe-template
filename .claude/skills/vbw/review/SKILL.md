# VBW 代码审查

所有 TODO 完成后，分两层验证代码质量。

## 前置条件

implement 阶段已完成，所有 TODO 项标记 `[x]`。

## 流程

### 1. 自检

当前 agent 快速过一遍基础检查（以下清单来自 workflow.md，已在上下文中可用）：

- [ ] 所有 TODO 项已标记 `[x]`
- [ ] 待解决已清空或全部转化为已确定
- [ ] 符合 `workflow.md` Code Review 清单：
  - [ ] models 是纯函数（无 `this`、无响应式 API）
  - [ ] 常量已收拢到 `constants.ts` 并加了 `as const`
  - [ ] 表单场景：`formData` 不含 UI 属性（UI 属性已放 `uiContext`）
  - [ ] 视图模板：无复杂表达式（如 `v-if="a && b"`）
  - [ ] 视图模板：无可选链防御链（如 `data?.xxx`）

### 2. 交叉审查

自检通过后，启动一个新的 agent 进行交叉审查：
- 注入干净上下文（无开发过程的历史对话）
- 提供 coding 规范（`coding.md`、`view.md`、`workflow.md`）和本轮变更的文件列表
- 新 agent 处于"聪明区"，能发现因上下文疲劳而忽略的边缘 Bug
- 审查结果：通过 → 继续；有问题 → 修复后重新自检

### 3. 修复循环

审查发现问题 → 修复 → 重新自检 → 重新交叉审查，直到全部通过。

## 门禁条件

- [ ] 自检清单全部通过
- [ ] 交叉审查全部通过
