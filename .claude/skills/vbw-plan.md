# 需求规划工作流

基于需求描述自动分析并生成规划文档。

## 触发条件

用户输入需求描述时触发

## 模式

- **有 superpowers**：调用 `superpowers:writing-plans` 生成基础计划，应用 rules/plan.md 约束（移除代码块、保留设计决策）
- **无 superpowers**：使用 vbw 内置逻辑

## 流程

### 1. 分析需求

从分支名提取需求编号，分析复杂度判断是否需要拆分。

### 2. 生成规划文档

- **单任务**：生成 `README.md`（完整任务内容）
- **多任务**：生成 `README.md`（总览含背景）+ 多个 `01-xxx.md`（只含目标）

### 3. 用户确认

展示拆分方案、依赖关系、预估变更文件，确认后写入文档。

### 4. 输出

创建 `docs/plans/<需求编号>/` 目录，提示执行 `@vbw-task` 开始开发。
