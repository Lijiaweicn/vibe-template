# 需求规划工作流

基于需求描述自动分析并生成规划文档。

## 触发条件

用户输入需求描述时触发

## 参数

- `requirement`: 需求描述文本
- `feature_branch`: 当前 feature 分支名（自动获取）

## 流程

### 1. 分析需求

- 从分支名提取需求编号（如 `feature/UAC-123-xxx` → `UAC-123`）
- 分析需求复杂度，判断是否需要拆分

### 2. 生成规划文档

**需要拆分（3+ 个计划）：**

```
docs/plans/<需求编号>/
├── overview.md
├── 01-<计划名称>.md
├── 02-<计划名称>.md
└── ...
```

**无需拆分（1-2 个计划）：**

```
docs/plans/<需求编号>/
├── 01-<计划名称>.md
└── 02-<计划名称>.md  # 可选
```

### 3. 用户确认

向用户展示：
- 任务拆分方案
- 各计划的依赖关系
- 预估变更文件

用户确认后写入文档，如有调整则修改后重新确认。

### 4. 输出

- 创建 docs/plans/<需求编号>/ 目录
- 生成对应的规划文档
- 提示用户可执行 `@task-workflow` 开始开发
