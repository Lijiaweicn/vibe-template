# Plan Rules

## 触发条件

满足以下任意条件时：

- 新需求开发
- 架构改造
- 目录调整
- 数据模型变更
- 跨领域修改

必须先生成规划文档。

---

## 文档目录

根据当前 Git 分支提取需求编号：

feature/UAC-123-xxx

↓

UAC-123

规划文档目录：

docs/plans/UAC-123/

---

## 文档格式

默认使用 ADR。

## ADR 模板

### Context

背景

### Problem

问题，如果存在信息缺失、需求歧义或技术决策未确定项，必须记录到此处，禁止自行假设。

### Decision

决策

### Consequences

影响

### Migration Plan

迁移计划

### Risks

风险

---

## 禁止事项

不要输出：

- 函数实现
- Class实现
- Vue组件代码
- API代码
- SQL代码
- Store代码

不要生成超过5行的代码块。

规划文档记录设计决策，
不记录实现细节。

---

## 优先输出

- ADR
- 表格
- 职责说明
- 目录结构
- 数据流
- 风险分析
