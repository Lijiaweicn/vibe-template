# CodeGraph 命令

## 用法

```
/codegraph [run|update|status]
```

## 参数

- `run` - 运行 CodeGraph
- `update` - 更新 CodeGraph
- `status` - 查看 CodeGraph 状态

## 执行

根据参数执行对应命令：

| 参数 | 执行命令 |
|------|----------|
| run | `npx @colbymchenry/codegraph` |
| update | `npx @colbymchenry/codegraph --update` |
| status | `npx @colbymchenry/codegraph --status` |
