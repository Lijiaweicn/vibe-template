# 🤖 AI (Claude) 研发协同总纲

为了确保代码在强类型下的绝对精准、不腐化，你必须在执行任何 Coding 指令前，无条件遵循以下认知：

## 🗺️ 1. 你的最高指导法典

项目的所有架构设计、分层规范与禁令红线，已全部固化。在分析或编写代码前，请必须先完整通读：

- ➔ `.claude/rules/01-architecture.md` (前端核心架构与分层规范)

## 🧰 2. 你的像素级肌肉记忆模具

项目拒绝任何口头上的“干净代码”指令。在生成新文件、重构老代码、定义接口类型或编写业务逻辑时，你**必须无条件像素级临摹、对齐**以下四份活打样：

1. **元数据声明标准** ➔ `.claude/samples/quote-constants.ts`
   _（学习重点：as const 字面量锁定、逆向类型推导、Options 数组输出）_
2. **通用领域事实** ➔ `.claude/samples/quote-common-models.ts`
   _（学习重点：顶级统一命名空间 `quoteModels` 导出、消费外部字典、全系统无魔法数字）_
3. **复杂表单场景模型** ➔ `.claude/samples/quote-form-models.ts`
   _（学习重点：formData 与 formContext 彻底双驱二分物理剥离、闭包平铺、无 this）_
4. **服务调度与防火墙** ➔ `.claude/samples/quote-form-index.ts`
   _（学习重点：异步请求封装、大门面单点对外纯解构导出）_

## 🚨 3. 黄金研发启动心智

- **当你面临新模块开发时**：主动声明你已阅读上述四份打样，并向用户简述你将如何拆分该模块的 `constants`、`models` 与 `services`。
- **当你面对极其简单的页面时**：主动评估是否触发法典第八条的【架构熔断条款】，向用户确认后实施降级，坚决不写过度设计的冗余代码。
